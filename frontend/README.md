# WEP Frontend

React + TypeScript frontend для Web Education Platform.

## Технологии

- TypeScript
- React 18
- Vite
- TailwindCSS
- React Query

## Архитектура

Feature-Sliced Design (FSD):
- app (bootstrap)
- pages (routes)
- widgets (composite blocks)
- features (user scenarios)
- entities (domain data)
- shared (ui-kit, api, utils)

## Установка

```bash
npm install

cp .env.example .env
# Отредактировать .env

npm run dev
```

## Доступ

http://localhost:5173
