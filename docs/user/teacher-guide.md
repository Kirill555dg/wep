# Руководство для преподавателя

## Создание теста

1. Откройте раздел **Мои тесты** (`/my-tests`).
2. Нажмите **Создать тест**.
3. Заполните поля:
   - **Название** — отображается в каталоге
   - **Описание** — поддерживает Typst-формулы (например, `$e^x$`), подробнее в разделе [Формулы](#формулы)
   - **Видимость**:
     - *Публичный* — виден всем студентам в каталоге
     - *Приватный* — виден только вам
   - **Ограничение по времени** (опционально) — минуты, после которых попытка автоматически завершится
   - **Лимит попыток** (опционально) — максимальное число прохождений
4. Нажмите **Опубликовать**.

## Редактирование теста

1. Откройте нужный тест из **Моих тестов**.
2. Нажмите **Редактировать**.
3. Внесите изменения в общие настройки.

## Добавление вопросов

### Типы вопросов

| Тип | Описание | Пример использования |
|---|---|---|
| **Один вариант (Single Choice)** | Один правильный ответ из списка | Выбор правильной формулы |
| **Несколько вариантов (Multiple Choice)** | Несколько правильных ответов | Выбор всех верных утверждений |
| **Текст (Text)** | Короткий текстовый ответ | Написание формулы |
| **Эссе (Essay)** | Развёрнутый ответ | Объяснение решения |
| **Сопоставление (Matching)** | Соединение пар | Термин — определение |
| **Загрузка файла (File Upload)** | Загрузка медиафайла | Рисунок, аудиозапись, PDF |

### Добавление вопроса

1. В режиме редактирования нажмите **Добавить вопрос**.
2. Выберите тип вопроса.
3. Введите текст вопроса.
4. Для вопросов с вариантами:
   - Добавьте варианты ответа
   - Отметьте правильные галочками
5. Укажите **Баллы** (целое число, по умолчанию 1).
6. Добавьте **Объяснение** (опционально) — студенты увидят его после завершения попытки.
7. Вопросы автоматически сохраняются.

### База вопросов (Question Pool)

1. В редакторе нажмите **Из пула**.
2. Поищите вопрос по ключевым словам.
3. Нажмите **Добавить** — вопрос с вариантами ответов будет скопирован в текущий тест.

## Медиа в вопросах

1. При редактировании вопроса нажмите **Добавить изображение**.
2. Выберите файл (BMP, PNG, JPEG, GIF, WebP).
3. Изображение загрузится в MinIO и отобразится в вопросе.

## Статистика

На странице теста (`/tests/{id}`) вы видите:

- **Общее число попыток**
- **Распределение баллов** — гистограмма
- **Статистика по вопросам** — процент правильных ответов
- **Таблица попыток** — имя студента, статус, балл, время

## Удаление теста

1. В **Моих тестах** наведите на карточку теста.
2. Нажмите иконку удаления.
3. Подтвердите. Все попытки и вопросы удалятся каскадно.

## Формулы (Typst)

Любое текстовое поле поддерживает Typst-разметку:

- Инлайн: `$ f'(x) = 3x^2 $`
- Блочная: `$$ integral_0^1 e^x dif x $$`
- Матрицы, дроби, системы уравнений — полная поддержка Typst

## Советы

- Добавьте объяснения к вопросам — студенты учатся на ошибках.
- Используйте публичные тесты для широкого охвата, а приватные для внутренних проверок.
- Ограничивайте время, если тест рассчитан на скорость решения.
