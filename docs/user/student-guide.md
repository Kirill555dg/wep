# Руководство для студента

## Каталог тестов

1. Откройте **Каталог** (`/catalog`).
2. Используйте поиск или теги для фильтрации.
3. Кликните на тест, чтобы открыть его страницу.
4. Нажмите **Начать тест** (или **Пройти снова**, если уже проходили).

## Прохождение теста

### Подготовка

- Убедитесь, что вы авторизованы.
- Проверьте описание теста — там могут быть ограничения по времени или числу попыток.

### Интерфейс теста

- **Верхняя панель**: таймер (если установлен) и кнопка **Finish**.
- **Боковая панель**: нумерация вопросов. Отвеченные вопросы отмечены зелёным.
- **Основная область**: текст вопроса, медиа, блок ответа.
- **Навигация**: **Previous** / **Next** или клик по номеру вопроса.

### Типы ответов

| Тип вопроса | Как отвечать |
|---|---|
| **Один вариант** | Клик по одному из вариантов |
| **Несколько вариантов** | Клик по каждому правильному варианту |
| **Текст / Эссе** | Введите текст в поле |
| **Сопоставление** | Перетащите или выберите соответствия |
| **Загрузка файла** | Нажмите область загрузки и выберите файл |

### Автосохранение

Ответы сохраняются автоматически:
- на сервер после каждого клика;
- в локальное хранилище браузера — если вы случайно закроете вкладку, при возвращении прогресс не пропадёт.

### Завершение

- Нажмите **Finish** на последнем вопросе или кнопку **Submit All**.
- После завершения тест нельзя редактировать.

## Просмотр результатов

После завершения открывается экран сводки:
- Общий балл (например, 4/4)
- Число правильных и неправильных ответов
- Время прохождения

Нажмите **View details** для детального разбора:
- Ваш ответ vs правильный
- Баллы за каждый вопрос
- Объяснение от преподавателя

## История попыток

Раздел **История** (`/history`) показывает:
- **Календарь активности** — зелёные ячейки показывают дни с попытками
- **График прогресса** — тренд баллов за 7 дней
- **Список попыток** с фильтрами: Все / Завершённые

## Возобновление попытки

- Если у теста есть **лимит попыток** и вы его исчерпали — кнопка **Начать тест** станет неактивной.
- Если попытка не завершена (статус *В процессе*), вы можете продолжить с того же места, открыв тест снова.

## Поддержка формул

В описаниях тестов и вопросах преподаватели могут использовать математические формулы. Они отображаются автоматически, ничего дополнительно делать не нужно.
