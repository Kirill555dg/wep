# Руководство для студента

Инструкция по работе с платформой для студентов.

## Начало работы

### Регистрация и вход

1. Перейдите на страницу регистрации
2. Заполните форму (имя, email, пароль)
3. Выберите роль "Студент"
4. Войдите в систему

## Присоединение к классу

1. Получите инвайт-код от преподавателя
2. Перейдите в раздел "Мои классы"
3. Нажмите "Присоединиться к классу"
4. Введите инвайт-код

## Просмотр уроков

- Список уроков доступен в классе
- Открывайте уроки для просмотра материалов
- Теория и дополнительные материалы

## Выполнение домашних заданий

### Начало выполнения

1. Откройте урок
2. Перейдите к домашнему заданию
3. Нажмите "Начать выполнение"

### Процесс выполнения

- Отвечайте на вопросы по порядку
- Можно пропускать вопросы и возвращаться к ним
- Черновики сохраняются автоматически
- Проверяйте ответы перед отправкой

### Отправка работы

1. Заполните все обязательные поля
2. Проверьте ответы
3. Нажмите "Отправить на проверку"
4. После отправки изменить ответы нельзя

### Просмотр результатов

- Баллы за каждую задачу
- Правильные ответы (после проверки)
- Комментарии преподавателя

## Личная статистика

### Мой прогресс

- Выполненные ДЗ
- Набранные баллы
- Средний балл по классу

### История попыток

- Список всех выполненных ДЗ
- Детализация по каждому заданию
- Динамика прогресса

## Чат класса

- Общение с одноклассниками
- Вопросы преподавателю
- Уведомления о новых сообщениях
