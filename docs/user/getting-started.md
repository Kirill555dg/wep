# Быстрый старт для пользователя

## Регистрация

1. Откройте страницу регистрации (`/register`).
2. Заполните поля: имя, email, пароль (минимум 8 символов, буквы разных регистров, цифра, спецсимвол).
3. Выберите роль: **Преподаватель** или **Студент**.
4. Нажмите **Зарегистрироваться**.

## Вход

1. Перейдите на страницу входа (`/login`).
2. Введите email и пароль.
3. Нажмите **Войти**. Сессия автоматически сохраняется в браузере.

## Выход

Нажмите на аватар в правом верхнем углу и выберите **Выйти**.

## Роли

| Роль | Что может |
|---|---|
| **Преподаватель** | Создавать тесты, добавлять вопросы, просматривать статистику попыток |
| **Студент** | Проходить тесты из каталога, видеть свои результаты и историю |
