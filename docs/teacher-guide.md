# Руководство для преподавателя

Инструкция по работе с платформой для преподавателей.

## Начало работы

### Регистрация и вход

1. Перейдите на страницу регистрации
2. Заполните форму (имя, email, пароль)
3. Выберите роль "Преподаватель"
4. Войдите в систему

## Управление классами

### Создание класса

1. Перейдите в раздел "Мои классы"
2. Нажмите "Создать класс"
3. Укажите название и описание
4. Получите инвайт-код для студентов

### Управление учениками

- Просмотр списка учеников в классе
- Удаление ученика из класса
- Просмотр статистики по ученику

## Работа с уроками

### Создание урока

1. Откройте класс
2. Перейдите на вкладку "Уроки"
3. Нажмите "Создать урок"
4. Заполните информацию (название, описание, материалы)

### Публикация урока

- Урок виден студентам только после публикации
- Можно изменить статус публикации в любое время

## Домашние задания

### Создание домашнего задания

1. Откройте урок
2. Нажмите "Создать ДЗ"
3. Выберите задачи из базы
4. Укажите баллы за каждую задачу
5. Опубликуйте ДЗ

### База задач

- Создание новых задач
- Редактирование существующих
- Указание правильных ответов
- Типы задач: текст, число, выбор варианта

### Проверка работ

- Автоматическая проверка (для закрытых вопросов)
- Ручная проверка (для открытых вопросов)
- Просмотр попыток студента

## Статистика

### Статистика класса

- Общий прогресс класса
- Средние баллы по ДЗ
- Активность студентов

### Статистика по ученику

- История выполнения ДЗ
- Детализация по каждому заданию
- График прогресса

### Статистика по ДЗ

- Количество выполнивших
- Средний балл
- Распределение оценок

## Чат класса

- Коммуникация со студентами
- Объявления
- Ответы на вопросы
