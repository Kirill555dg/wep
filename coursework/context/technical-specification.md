# Техническое задание

## Система управления образовательными курсами

### Задачи

1. Провести анализ предметной области (сравнить аналоги, выделить функционал, сформировать матрицу отслеживаемости)
2. Обосновать выбор технологий (сравнить паттерны: DDD, Clean Architecture, MVC)
3. Разработать архитектуру на основе Clean Architecture
4. Реализовать серверную логику (FastAPI)
5. Реализовать слой базы данных (PostgreSQL)
6. Разработать клиентское представление (React, TypeScript)

### Технологии (из задания)

- **Backend**: Python 3.12+, FastAPI
- **Frontend**: TypeScript, React
- **БД**: PostgreSQL
- **Паттерн**: Clean Architecture
- **API**: REST
- **IDE**: Visual Studio Code

### Требования

- Межстраничная навигация
- Современный веб-дизайн
- Соответствие ГОСТ 7.32-2017
