# Тема курсовой работы

**Серверная часть веб-приложения для управления образовательными курсами**

## Предметная область
Система управления образовательными курсами (LMS) для онлайн-обучения.

## Что входит в работу
- Анализ предметной области
- Обоснование выбора технологий (Python, FastAPI, PostgreSQL, React)
- Разработка архитектуры (Clean Architecture)
- Реализация серверной логики и REST API
- Реализация слоя базы данных
- Разработка клиентского интерфейса
