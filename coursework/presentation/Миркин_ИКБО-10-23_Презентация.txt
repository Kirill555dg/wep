    Цель работы:
    разработка архитектуры системы управления онлайн-обучением с поддержкой

характерные для онлайн-обучения;
    – сформулировать требования к системе, а также определить ограничения проекта;
    – провести обзор архитектурных стилей и выполнить их сравнительный анализ;
    – разработать набор архитектурных диаграмм;
    – изучить и описать паттерны проектирования;
    – обосновать выбор технологического стека;
    – спроектировать и описать прототип.                                             2
                       Описание предметной области
    Предметная   область   разрабатываемой   системы   включает   несколько   ключевых
компонентов:

    – учебные курсы, содержащие теоретические материалы, практические задания, тесты и
мультимедийные ресурсы;

    – пользователей с различными ролями, среди которых администраторы, преподаватели и
обучающиеся;

    – механизмы тестирования и оценки знаний, обеспечивающие контроль усвоения
материала;

    – хранилище данных, в котором содержится информация о пользователях, курсах,
результатах тестирования и связанных учебных артефактах.

   Используемые технологии для серверной части

Для реализации серверной части платформы были выбраны следующие технологии:

    – FastAPI — современный высокопроизводительный веб-фреймворк

    – Pydantic — библиотека для валидации данных и работы с моделями

    – SQLAlchemy — популярный инструмент объектно-реляционного отображения

    – Alembic — система миграций базы данных для SQLAlchemy

              Архитектура серверной части проекта


                                    Архитектура      сервера    основана     на     паттернах
                             разделения             ответственности.         Бизнес-логика
                             организована       в     виде     Service   Layer,      который
                             централизует операции с пользователями, курсами и
                             тестами. Data Mapper и Repository изолируют доступ к
                             базе     данных.        Dependency     Injection       управляет
                             зависимостями,         снижая     связанность      и    упрощая
                             тестирование.      Контроллеры        обрабатывают        HTTP-
                             запросы, а DTO обеспечивают строгую валидацию
                             данных. В совокупности это создаёт устойчивую, легко
Паттерн разделения на слои   поддерживаемую основу.

       Используемые технологии для клиентской части

    Для реализации клиентской части платформы были выбраны следующие технологии:

        – React — библиотека для создания пользовательского интерфейса

        – Vite — инструмент сборки с мгновенной перезагрузкой

        – Tailwind CSS — утилитарная система стилей

        – ShadCN UI — библиотека компонентов на основе Radix UI

        – Zustand — управление состоянием без лишней сложности


+       – React Hook Form + Zod — формы и валидация данных
